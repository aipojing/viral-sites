# 01 · 人生进度条（首发站）

> 2026-08-04 · 状态：设计完成，待实现 · 形态：纯前端，零运行成本

## 1. 一句话

输入出生日期，看到自己的人生被画成 4000 个格子——走过的涂黑，剩下的留白——配上几条扎心但不绝望的数字，然后忍不住保存那张卡片发出去。

## 2. 传播机制

- **情绪钩子**：存在焦虑 + 时间稀缺感（「还能见父母 52 次」是全网验证过的最强扎心文案之一）
- **转发动机**：扎心（发群里「你们也来测测」）+ 自我表达（配文「过好每一天」发朋友圈）
- **传播载体**：结果卡片（格子图视觉冲击力强，缩略图就能看懂，不需要点开链接）
- **对标**：英文圈 Life in Weeks / your-life-in-weeks 长盛不衰；中文没有做得精致的，差异化 = 中文语境文案 + 卡片质感

## 3. 用户流程（两屏，全程 < 30 秒）

```
输入屏：选出生日期 →（可选高级项）→ 点「看看我的人生」
结果屏：格子图 → 扎心数字 → 「保存我的人生卡片」
```

无注册、无等待、无弹窗。所有计算在浏览器本地完成，页面明示「你的生日不会被上传」。

### 3.1 输入屏

- **出生日期**：年月日选择器，默认聚焦，支持直接键盘输入；这是唯一必填项
- **高级选项**（折叠，默认不展开，给较真的用户）：
  - 预期寿命滑块：60 ~ 100，默认 78（中国人均预期寿命取整）
  - 父母年龄：默认「我的年龄 + 28」，可改
  - 每年见父母次数：默认 2（在外地工作的典型值），可改
- 校验规则：
  - 未来日期 → 「你还没出生，不用焦虑」
  - 年龄 > 120 → 「恭喜您打破吉尼斯纪录」+ 拒绝
  - 非法日期（2 月 30 日等）由选择器杜绝

### 3.2 结果屏

**块一：人生格子图（视觉锤）**

- 一行 = 一年（52 格），共 `预期寿命` 行，默认 78 行 ≈ 4056 格
- 走过的周：实色填充；**本周：高亮 + 呼吸动画**（「你在这里」的震撼点）；未来：细线空格
- canvas 绘制（4000+ 格 DOM 必卡），支持 devicePixelRatio 高清渲染
- 格子上方一行小字：「一格是一个星期，这就是你的一生」

**块二：扎心数字区（文案是核心资产）**

按情绪节奏排列，逐条滚动淡入，最后一条给正向收尾：

| # | 文案模板 | 计算 |
|---|----------|------|
| 1 | 你的人生已经走过 **{p}%** | `p = 已过周数 / 总周数`，保留 1 位小数 |
| 2 | 从出生到今天，你已经用掉 **{n}** 个星期 | `n = floor((today - birth) / 7天)` |
| 3 | 按一年见 **{k}** 次算，你还能见父母大约 **{m}** 次 | `m = max(0, 78 - 父母年龄) × k` |
| 4 | 这辈子还剩 **{c}** 个春节 | `c = max(0, 预期寿命 - 当前年龄)` |
| 5 | 距离 60 岁退休，还有 **{w}** 个工作日 | `w = max(0, (60 - 当前年龄)) × 250` |
| 6 | 剩下的 **{b}** 个格子还是空白，怎么填由你 | `b = 总周数 - 已过周数` |

边界与彩蛋（认真处理，这是口碑细节）：

- 父母年龄 ≥ 78：第 3 条改为「**每一次见面，都是赚到**」（不显示 0 次这种残忍数字）
- 当前年龄 ≥ 60：第 5 条改为「你已经熬过了所有工作日」
- 当前年龄 ≥ 预期寿命：整体进入彩蛋模式——「你已经多赚了 {x} 个星期，接下来每一格都是奖励」（格子图全涂 + 金色溢出行）
- 文案配置化（JSON），改文案不动代码，为 A/B 迭代留口

**块三：保存卡片按钮**

主按钮「保存我的人生卡片」，点击生成卡片（见 §4）。次要入口「重新计算」回输入屏。

## 4. 分享卡片

- 3:4 竖版 1080×1440，走 `shared/share-card` 管线（微信长按保存 / 桌面下载 / 失败降级，见 [00 工厂设计 §4.2](00-factory-design.md)）
- 卡片构成（从上到下）：
  1. 完整格子图（卡片版可简化为色块热图，保证缩略图清晰）
  2. 一条主文案：默认取「已走过 {p}%」+「还能见父母 {m} 次」中更扎心的一条（规则：有父母数据用父母条，否则用百分比条）
  3. 底部品牌条：站名 +域名文字（正式域名后加二维码）
- 卡片配色与站内一致（作业本纸感 + 红笔批改），格线纸底在九宫格缩略图里辨识度高

## 5. 视觉调性（2026-08-04 修订，见 [00a 风格分配表](00a-style-map.md)）

**方格作业本**——你的人生是一本写到一半的作业本。「一格一个星期」与作业本方格天然同构；「本周」的红格是老师的红笔批改，百分比大数字像红笔打的分。

- 纸白底 `#f7f4ec` + 浅青蓝作业本格线铺底（CSS 渐变实现，不用图）
- 铅笔灰 `#8c8678` 涂过去的格子与辅助文字；墨色 `#3a3833` 正文
- 批改朱红 `#c8392b` 只用在三处：本周格、关键数字、主按钮——红笔是唯一的强调
- 中文标题用衬线字（v1 系统宋体族兜底，思源宋体子集化列入上线后优化），正文无衬线
- 无任何营销元素：无弹窗、无引导关注、无红点。信任感本身是传播力
- 修订原因：原「近黑底+单一暖橙」是 AI 生成设计的高频模板脸，作业本方向概念咬合更紧、中文语境记忆点更强

## 6. 技术要点

- 纯前端，无后端无存储；构建目标：首屏资源 < 100KB（gzip 后，字体子集另计）
- 核心计算全部纯函数，集中在 `lib/life-math.ts`：
  - `weeksLived(birth, today)` / `totalWeeks(expectancy)` / `percentLived(...)`
  - `parentMeetings(parentAge, perYear)` / `remainingFestivals(...)` / `workdaysToRetire(...)`
  - 全部接受显式 `today` 参数（可测性；杜绝隐式取当前时间）
- 埋点：`visit` / `generate`（点「看看我的人生」）/ `save_image`（触发卡片保存或长按提示曝光）
- SEO 白送部分：标题「人生进度条 — 你的人生还剩多少个星期」，描述带「还能见父母多少次」关键词

## 7. 测试

- `life-math` 纯函数单测（vitest）：常规值 + 全部边界（未来日期、>120 岁、父母 ≥78、年龄 ≥ 预期寿命、闰年、今天生日当天）
- 卡片导出 smoke test：给定固定输入，canvas 能产出非空 blob
- 手工验收清单：iPhone 微信、安卓微信、iOS Safari、桌面 Chrome 四个环境的保存路径各走一遍

## 8. 上线检查清单

- [ ] 四环境保存卡片路径手工验证通过
- [ ] 埋点三事件在 umami 后台可见
- [ ] 首屏资源 < 100KB（gzip）
- [ ] 文案过一遍「扎心但不绝望」的尺度审（没有让人看完想哭而不想转的条目）
- [ ] 页面明示「所有计算在本地完成，生日不会被上传」
- [ ] 冷启动：朋友圈 + 2 个群 + 小红书发一轮，记录首日数据

## 9. 风险

| 风险 | 应对 |
|------|------|
| 情绪太丧，看完沉重不想转 | 文案尺度：每条扎心必须配可行动感；结尾必须正向；灰度看保存率调整 |
| 「见父母次数」文案被指贩卖焦虑 | 该条来自用户自己填的参数，页面提供修改入口；卡片主文案可切换 |
| 同类产品已存在 | 差异化 = 中文文案质量 + 卡片质感 + 本周呼吸动画的临场感 |

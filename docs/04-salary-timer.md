# 04 · 上班回本计算器（备选池）

> 2026-08-04 · 状态：备选，暂不排期 · 形态：纯前端
> 触发条件：前三发验证完管线与量产模式后，若需要补充「办公室场景」品类再启动

## 1. 一句话

输入月薪和作息，屏幕上实时跳动「今天已赚 ¥187.43」——外加「本次带薪如厕价值 ¥3.2」「这个会开掉了你 ¥45」，把摸鱼变成看得见的收益。

## 2. 传播机制

- **情绪钩子**：打工人自嘲 + 「原来我这泡尿这么值钱」的荒诞快感
- **转发动机**：办公室同事间口口相传（「你也去算算」）；截图实时跳动的数字发群
- **场景优势**：工作日每天可用（复访属性是四个点子里最强的），适合做成常驻标签页
- **对标**：「摸鱼办」验证过品类；已有竞品是本站最大问题，差异化见 §4

## 3. 玩法设计

- **主界面**：一个大数字实时跳动（今日已赚），按秒增长；副信息：本月已赚、距下班还有 X 小时（价值 ¥Y）
- **摸鱼计价器**（差异化核心）：一组一键开始/结束的「计价场景」——带薪如厕、带薪开会、带薪发呆、带薪骂老板（心里）；结束时弹出「本次如厕收益 ¥3.2，超过全国 87% 的打工人」可保存卡片
- **收益日报卡**：下班时生成当日总结卡（今日总收入 + 摸鱼收益占比 + 一句锐评），是本站的传播卡片
- 输入项：月薪、每周工作天数、上下班时间；**全部只存 localStorage，明示绝不上传**（工资是最敏感的输入，本地化是硬前提也是信任卖点）

## 4. 与竞品的差异化

| 竞品现状 | 本站做法 |
|----------|----------|
| 只有一个跳动数字，看一眼就关 | 摸鱼计价器给了「持续交互」的理由 |
| 界面糙，像站长工具 | 工厂质感标准：精致到值得截图 |
| 没有传播卡片 | 场景收益卡 + 下班日报卡两个保存点 |

## 5. 技术要点

- 纯前端；收益计算为纯函数（输入薪资参数 + 起止时间戳 → 金额），显式传入时间，可测
- 实时跳动用 rAF 节流到每秒更新，标签页后台时暂停渲染（省电，回前台跳补差值）
- 埋点：`visit` / `generate`（完成设置开始计时）/ `save_image`，另加 `scene_used`（带场景名）看哪个摸鱼场景受欢迎
- 卡片走 `shared/share-card`

## 6. 启动前需要回答的问题

- 「摸鱼办」等竞品当前的存活状态与流量（届时调研，若品类已死要弄清死因）
- 复访型产品与工厂「一次性传播」模式的指标体系差异：本站要看的是**次日留存**而不只是保存率，启动时需补充留存埋点方案

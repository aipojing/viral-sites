# 11 · 拒绝话术生成器（A 级）

> 2026-08-04 · 状态：设计完成，排队 · 形态：v1 纯前端模板库；v2 轻 AI（复用 03 管线）
> 本站核心指标是**复制率**不是保存率（实用工具属性）

## 1. 一句话

选场景（被借钱 / 被拉砍价 / 被安排相亲 / 被叫加班）+ 语气（委婉 / 硬刚 / 发疯文学 / 文言文）→ 一键复制拒绝话术，或保存「今日拒绝语录」卡。

## 2. 传播机制

- **实用价值**：拒绝是高频真实痛点，「不会拒绝」的人会主动搜索和收藏
- **情绪钩子**：发疯文学式拒绝自带喜剧效果（「实在抱歉，我的钱在我这儿也是好好的」），截图发群
- **转发动机**：话术卡截图（「学着点」）+ 转给正在为难的朋友（定向转发）
- **对标**：小红书上「拒绝话术」笔记是常青内容形态，但都是静态图文；可交互生成器是空档

## 3. 玩法设计

```
首页：场景九宫格（icon + 名称）→ 选语气（横向胶囊）→ 出话术（3 条候选，可换一批）
每条话术：[复制] + [保存为卡片]；可填「对方称呼」变量个性化
```

- **场景 × 语气矩阵**（v1）：8 场景 × 5 语气 = 40 组，每组 ≥3 条 = **120+ 条文案资产**（本站的真正产品）
  - 场景：被借钱 / 被拉群砍价 / 被安排相亲 / 被叫周末加班 / 被推销办卡 / 被要份子钱 / 被要求帮忙搬家 / 被拉去团建
  - 语气：委婉体面 / 直球硬刚 / 发疯文学 / 文言文 / 职场黑话（「这个需求我评估了下 ROI 不高」）
- 模板变量：`{对方称呼}` 可选填空替换（默认「亲」/「哥」中性词）
- 文案标准：每条都要过「敢真的发出去」测试——好笑但不至于绝交（发疯文学档除外，那一档的定位就是「解压看的」）

## 4. v2 轻 AI 升级（触发条件：v1 复制率 > 15%）

- 加自由输入框「描述你的具体处境」→ Workers 代理 LLM 生成个性化话术，完全复用 [03 判官](03-ai-judge.md) 的限流/缓存/预算熔断/内容过滤管线
- v1 先验证需求存在，再为需求付接口成本——顺序不能反

## 5. 分享卡片

- 「今日拒绝语录」卡：话术正文大字 + 场景角标 + 品牌条；语气不同视觉皮不同（文言文出竖排仿古皮，发疯文学出高饱和 meme 皮）

## 6. 埋点（特殊）

- 标准三事件 + **`copy`（核心指标）**：复制率 = copy / visit，生死线 15%（实用工具的「用了」比「晒了」重要）
- `scene_selected` / `tone_selected`：矩阵热力数据，决定 v1.1 往哪个场景加文案

## 7. 测试

- 模板变量替换纯函数单测（空值/超长称呼/特殊字符）
- 文案库 lint：矩阵完整性（40 组无空洞）、字数上限、变量占位符合法
- 复制到剪贴板在微信内置浏览器的兼容性手工验收（clipboard API 降级到 execCommand）

## 8. 风险

| 风险 | 应对 |
|------|------|
| 模板文案不够好 = 地摊货 | 120 条按「敢真的发出去」标准逐条打磨；文案质量是本站唯一壁垒，写不出就不上线 |
| 场景覆盖不全，用户想要的没有 | 首页放「想拒绝别的？」许愿入口（mailto 或表单链接），许愿数据决定扩展方向 |
| 复制了但不传播（流量不滚动） | 接受工具属性，收藏/复访是本站的「传播」形态；卡片皮肤（文言文/发疯）负责社交侧露出 |

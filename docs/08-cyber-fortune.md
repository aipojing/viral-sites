# 08 · 赛博求签（S 级）

> 2026-08-04 · 状态：设计完成，候选排期 · 形态：纯前端，签文库驱动，零运行成本

## 1. 一句话

打工人电子黄历：每天求一签——「宜摸鱼，忌当出头鸟；今日贵人：食堂阿姨」——生成今日运势卡，明天又是新的一签。

## 2. 传播机制（为什么是 S 级）

- **复访结构**：池子里唯一「每天有新内容」的纯前端点子。签文由 `hash(昵称 + 日期)` 决定：同一个人每天不同签，同一天不同人不同签——**当天可对比（群里晒签比运势），明天有理由回来**
- **情绪钩子**：玩梗化的运势自嘲（「忌开会」发在会前的群里）+ 轻微的仪式感成瘾
- **转发动机**：签文卡截图发群是已验证的社交行为（黄历梗、星座日签常青）；「连续求签 N 天」streak 是炫耀点
- **对标**：星座日签 App 常青；网页端「打工人黄历文学」精致版是空档

## 3. 用户流程

```
首页：签筒 → 输入昵称（记住上次的）→ 长按签筒蓄力 → 松手掉签（动效 1.5 秒）
结果：今日签文卡（等级 + 签诗 + 宜忌 + 贵人/小人 + streak）→ 保存卡片
```

- 同人同天重复求签得同一支签（hash 保证），文案提示「心诚，一天一签」——把技术约束讲成产品设定
- 昵称与 streak 存 localStorage；无后端无账号

## 4. 签文结构与内容库（核心资产）

一支签 = 整签部分（hash 选取）+ 组合部分（hash 抽取），兼顾质量与组合数：

```
签 {
  等级：大吉 / 中吉 / 小吉 / 平 / 小凶（无大凶，凶签也要好笑）
  签诗：一句手写梗诗（验证版 40 条，每条绑定等级）
  宜 ×2：宜池抽取（验证版 30 条：宜摸鱼 / 宜带薪喝水 / 宜已读不回 / 宜准点下班…）
  忌 ×2：忌池抽取（验证版 30 条：忌当出头鸟 / 忌在群里发言 / 忌点开工作消息…）
  今日贵人 / 小人：人物池抽取（验证版 20 条：食堂阿姨 / 上一个离职的同事 / 电梯里的陌生人…）
}
```

- 验证版组合空间：40 × C(30,2) × C(30,2) × 20²，足以覆盖首轮 D7 实验；只有 D7 复访成立后才扩到 100 / 50 / 50 / 30，避免在需求验证前透支文案产能
- 等级分布加权：大吉 15% / 中吉 30% / 小吉 30% / 平 15% / 小凶 10%——整体偏正向，小凶的签诗必须是全库最好笑的（坏运势 + 好文案 = 最强截图欲）
- **节令皮系统**：日期命中配置区间时替换皮肤与专属签池——新年签（1 月下旬）、高考签（6 月上旬）、发薪日横财签（每月固定日全站彩蛋）。皮 = 配置 + 专属池，不改引擎

## 5. Hash 与确定性规则（`lib/fortune-math.ts`）

- `seed = fnv1a(normalize(昵称) + "2026-08-04" + 签池版本号)`；normalize：trim + NFC + 小写化英文
- 所有抽取（等级/签诗/宜/忌/人物）从同一 seed 派生的确定性序列取，**保证同输入同输出**（可测、可跨设备复现：换手机同昵称同签，这是「玄学感」细节）
- 签池版本号进 seed：改库不改变「当天已求过的人」的签（当天版本冻结策略：池子更新次日生效）
- 显式传入日期参数，可测；时区固定 UTC+8（页面用户几乎全在国内，避免出海时区 bug 打断 streak）

## 6. Streak（复访机制）

- localStorage 记录连续求签天数；中断即清零，卡片上显示「连续求签第 N 天」
- streak 是卡片上的炫耀元素，不做任何奖励发放（避免变成任务感）；≥7 天时卡片加一枚「虔诚」印章
- 明确不做：补签、提醒推送（v1 无后端做不了，也不该做——靠内容拉复访，不靠打扰）

## 7. 分享卡片

- 3:4 竖版，走 `shared/share-card`；视觉：现代黄历美学——纸纹底 + 大字等级 + 竖排签诗 + 朱红印章（与 [03 判官](03-ai-judge.md) 的公文美学区分：判官是审你，黄历是保佑你）
- 等级不同配色不同，群里多人晒签时一眼可比（这是「群内对比」传播的视觉基础）

## 8. 合规（上线硬门槛）

- 去宗教化：不出现任何真实宗教元素（不用佛/道符号、不用「拜」「神」字眼），定位「电子黄历文学」
- 页面明示：「签文为程序生成的玩梗内容，不构成任何预测与建议」
- 签文内容红线：不涉医疗、投资、婚恋决策的「建议式」表述（「宜买入」这类词进内容黑名单，构建期 lint 检查签池）

## 9. 埋点

标准三事件（`generate` = 掉签）+ `streak_day`（求签时带当前 streak 值，看复访分布）。本站核心指标除保存率外，加**7 日复访率**（预期 > 15%）。

## 10. 测试

- fortune-math 单测：同输入同输出、跨设备一致性（纯函数即保证）、等级权重分布（统计测试）、宜忌冲突黑名单生效、节令区间命中、时区固定
- 签池 lint（构建期脚本）：字数超限、黑名单词、冲突对完整性
- streak 逻辑单测：连续/中断/跨月/当天重复求签不重复计数

## 11. 风险

| 风险 | 应对 |
|------|------|
| 「求签」外皮触发平台对封建迷信的审核 | §8 全套去宗教化 + 玩梗声明；卡片视觉走「黄历文学」不走「灵签」 |
| 签文库产能（好文案是持续投入） | 验证版先交付 40+30+30+20 条；D7 复访成立后扩到 100+50+50+30，并再决定是否每周补 10 条 |
| streak 依赖 localStorage，清缓存即断 | 接受（v1 无账号是刻意选择）；卡片文案不渲染「断签惩罚」概念，断了明天接着求 |

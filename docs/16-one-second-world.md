# 16 · 一秒钟世界（B 级 · 简版设计）

> 2026-08-04 · 状态：待触发 · 触发条件：工厂需要「镇店之宝」提升整体格调时（品牌件，不以保存率考核）
> 形态：纯前端，统计数据驱动

## 1. 一句话

你打开这个页面的 47 秒里，世界上出生了 12 个人，卖出了 3,290 杯奶茶，有 141 万条微信消息发出——数字从你进来那一刻开始实时累积。

## 2. 传播机制

neal.fun 式的「宏大数字具象化」审美（对标 The Size of Space 的品牌效应）；「从你进来开始算」的第一人称视角是与同类数据页的差异化。传播上限存疑（B 级原因）：数字实时变化导致截图无意义、玩一次即懂。**定位是品牌件**——给工厂攒口碑和外链（这类站容易被科技媒体/公众号收录引用），不指望保存率。

## 3. 玩法要点

- 进入即开始累积；条目按「震撼梯度」滚动展开（出生 → 消费 → 信息 → 宇宙尺度：「地球带着你飞了 1,410 公里」）
- 每条数据：速率 × 停留秒数，速率来自公开统计（联合国出生率、行业年报换算），**来源备注必填**（同 09 的考证制度，被扒错数据是品牌件的死穴）
- 条目库 20 条起步，中文语境专属条目是差异化重点（奶茶、外卖单、高铁发车）

## 4. 截图问题的解法（立项前必须想清楚的点）

「数字一直在变，截图无意义」的破法：**快照卡**——点击「定格这一刻」，生成「我在这里的 47 秒，世界发生了什么」快照卡（时刻戳 + 3 条最震撼数字）。把流动的页面变成可保存的瞬间，是本站能不能超出品牌件定位的关键实验。

## 5. 技术与启动前问题

- 纯前端；速率表 JSON + 构建期 lint（来源非空、单位换算校验）；rAF 节流，后台暂停累积（同 04 的省电策略）
- 启动前回答：中文语境条目能不能凑够 10 条有来源的硬数据？（凑不够质感就崩，宁缺毋滥）

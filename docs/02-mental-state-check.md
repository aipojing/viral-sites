# 02 · 精神状态检测系列（第二发）

> 2026-08-04 · 状态：设计完成，待实现 · 形态：纯前端，配置驱动，可量产

## 1. 一句话

8 道好笑的题，测出你的「班味浓度」，生成一张可以晒的报告卡——而且这是一个**模板**：换一套 JSON 配置就是一个新测试站。

## 2. 为什么是第二发

- 复用首发站打磨好的管线（卡片、埋点、部署），验证工厂的**量产能力**
- 测试类是中文社交的常青形态（小红书受众极吃这套），单个测试生命周期短，但模板在手可以持续换皮
- 纯前端规则驱动，零运行成本，点子试错密度最高

## 3. 传播机制

- **情绪钩子**：自嘲 + 身份认同（「我就是班味十级」）+ 好笑
- **转发动机**：晒报告卡（自嘲式炫耀）+ 拉人对比（「你测测你多少」）
- **题目即内容**：题目本身要好笑到值得截图——这是和垃圾测试站的核心区别。用户在答题过程中就想截图某道题发群里
- **对标**：网易哒哒 H5 测试刷屏时代验证过形态；现在小红书上「xx 浓度测试」仍持续有自然流量

## 4. 引擎设计（模板化是本站的真正产品）

一个测试 = 一份 JSON 配置，引擎负责渲染和计分：

```
TestConfig {
  meta:      { 标题, 副标题, 主题色, 站点 slug }
  questions: [ { 题干, 选项: [{ 文案, 分值 }] } ]   // 固定 8 题，3~4 选项
  scoring:   { 分档: [{ 最低分, 称号, 浓度区间, 报告文案[3], 解药文案 }] }  // 5 档
  card:      { 卡片主视觉参数（称号字号/配色/图案种子） }
}
```

- 引擎不含任何具体测试的文案；换皮 = 新增一份配置 + 新站点入口
- 计分：选项分值求和 → 落入分档 → 浓度百分比在档位区间内按得分线性映射（同档不同分显示不同百分比，增加「我 87% 你 83%」的对比谈资）
- 报告卡：称号 + 浓度大数字 + 3 条锐评 + 1 条「解药」（正向收尾，同 01 的文案哲学）

## 5. 首个主题：班味浓度检测

- 受众：打工人，办公室场景传播（同事间互测）
- 题目方向（8 题，实现期逐题打磨，每题都要过「值得截图」标准）：
  1. 周日晚上的心情曲线
  2. 「收到」两个字你一天打几次
  3. 对工位绿植的感情
  4. 电梯里遇到老板的反应
  5. 「下班后学习提升」坚持了几天
  6. 年假的使用方式
  7. 微信步数在工作日的表现
  8. 听到「团建」两个字的生理反应
- 分档示例：`班味清新（<20%）/ 微微入味 / 腌制中 / 深度腌入味 / 班味十级学者（>85%）`
- 后续换皮主题池：恋爱脑浓度、互联网黑话浓度、发疯文学等级、「懂王」浓度（争论时装懂程度）——每个主题独立评估，不预先承诺

## 6. 用户流程

```
落地页（标题 + 一句挑衅文案 + 开始按钮）
→ 答题（一屏一题，点选即跳下一题，无返回焦虑，顶部细进度条）
→ 报告卡（自动生成 → 保存卡片按钮）
```

- 全程 < 60 秒；答题动效轻快（和 01 的冷静调性区分，本站调性是「轻快、贱兮兮」）
- 结果页文案明示「测试纯属玩梗，别当真」

## 7. 技术要点

- 引擎 + 配置分离：`sites/mental-state` 内 `engine/`（渲染、计分、卡片数据组装）与 `configs/*.json`
- 计分与分档映射为纯函数，单测覆盖（含边界：全选最低分、全选最高分、档位边界分值）
- 卡片走 `shared/share-card`；规格同工厂标准（3:4，底部品牌条）
- 埋点：`visit` / `generate`（出报告）/ `save_image`，另加 `q_answered`（带题号）算**完测率**——测试类特有的质量指标，题目不好笑的位置会直接反映为流失点
- 路由预留 `?t=<slug>` 支持同站多测试，换皮不换域名（验证期）；爆款主题再拆独立站

## 8. 测试

- 计分纯函数单测（vitest）：三档边界值、线性映射正确性、配置校验（题数/选项/分档完整）
- 配置 schema 校验：加载时用 zod 验证 JSON，坏配置直接构建期报错
- 手工验收：四环境保存路径（同 01 清单）

## 9. 风险

| 风险 | 应对 |
|------|------|
| 测试类竞争激烈、审美疲劳 | 靠题目文案的梗密度取胜；每个主题上线前过「8 题里至少 3 题想截图」的自审 |
| 单个测试生命周期短（1~2 周热度） | 这正是模板化的意义：热度衰减就换皮，配置成本半天 |
| 被指「没有科学依据」 | 页面自带免责玩梗声明；调性贱兮兮，不装权威 |

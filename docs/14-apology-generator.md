# 14 · 道歉信 / 请假条生成器（B 级 · 简版设计）

> 2026-08-04 · 状态：待触发 · 触发条件：11 拒绝话术生成器验证成功（复制率 > 15%）后，作为「话术矩阵」第二件
> 形态：纯前端，复用 11 的话术引擎

## 1. 一句话

选对象（老板 / 对象 / 老师 / 甲方）+ 事由 + 语气（诚恳 / 卑微 / 文言文 / 发疯文学）→ 生成整段道歉信或请假条，一键复制。

## 2. 传播机制

与 11 同构（实用 + 好笑截图），但更弱：道歉/请假的使用频率低于拒绝，且「晒道歉信」的社交动机存疑（真道歉不会晒，晒的是玩梗）。故定位为 11 的**矩阵扩展**——共享话术引擎（场景 × 语气 × 模板变量），边际成本只有文案。

## 3. 玩法要点

- 与 11 的差异：输出是**整段文书**（100~200 字）而非一句话术，模板变量更多（`{对象称呼}` `{事由}` `{日期}`）
- 场景矩阵 v1：道歉（迟到 / 忘回消息 / 忘纪念日 / 放鸽子）× 请假（病假 / 事假 / 精神离职假〔玩梗〕）
- 「发疯文学请假条」是本站的截图担当，文案往喜剧写；「诚恳」档往真能用写——两个极端都要能打

## 4. 技术与埋点

- 话术引擎从 11 抽到 `shared`（模板渲染 + 变量替换 + 文案库 schema），11 先建、本站换皮——顺序即依赖
- 核心指标同 11：复制率；卡片保存为次要

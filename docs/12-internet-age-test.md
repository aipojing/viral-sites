# 12 · 网感年龄测试（A 级）

> 2026-08-04 · 状态：设计完成，排队 · 形态：纯前端，[02 测试引擎](02-mental-state-check.md)首个换皮 + 引擎多维计分升级

## 1. 一句话

认不认识各年代的梗（贴吧时代 / QQ 空间 / 微博体 / 抽象话 / 最新黑话），测出「你的互联网精神年龄 34 岁：60% 贴吧遗老 + 30% 抽象人 + 10% 小红书新贵」。

## 2. 传播机制

- **情绪钩子**：代际认同 + 怀旧暴击（「这梗我居然还记得」）+ 自嘲（精神年龄比实际大）
- **转发动机**：成分报告比单一分数谈资多一个维度（「我 60% 贴吧遗老，你呢」）；拉长辈/00 后对测的代际对比玩法
- **对标**：网易云年度报告验证了「成分/标签化报告」的传播力；梗考试类 H5 爆过多轮，常青

## 3. 对工厂的基建价值（本站立项的另一半理由）

02 引擎目前是单维加权计分。本站需要**多维 tag 计分**：每个选项带 `tags: { 贴吧: 2, 抽象: 1 }`，结果按 tag 聚合出成分占比 + 由成分加权推出「精神网龄」。

- 引擎升级为 v2：`scoring.mode: "linear" | "tags"`，向后兼容 02 的存量配置（linear 默认）
- 升级后测试引擎能出「成分报告」类结果，后续换皮题材空间翻倍（一切「XX 成分检测」皆可做）
- 单测覆盖两种模式与混合配置的校验

## 4. 题库设计（8 题，配置化）

- 每题一个梗识别场景，选项跨年代（认识哪个版本暴露你的年代）：
  - 示例题干方向：「看到『蓝瘦香菇』你的第一反应」「以下哪个是你先学会的告别方式：88 / 拜拜了您嘞 / 溜了溜了 / 润了」「『家人们』这个词你用在哪」
- 选项 tag 池（v1 五维）：贴吧遗老 / QQ 空间贵族 / 微博冲浪元老 / 抽象人 / 小红书新贵
- **时效校准制度**：题库带「梗年代标注」字段，实现期请两位不同年龄段的真人过一遍题库（老梗认定错误会被评论区嘲，这是本站最大口碑风险）；上线后每季度审一次时效
- 精神网龄计算：各 tag 绑定一个「年代锚点年龄」，按成分占比加权平均，再加离散扰动使同成分不同分（配置化公式，纯函数单测）

## 5. 报告卡

- 成分条形图（横向占比条，颜色区分年代）+ 精神网龄大数字 + 称号（主成分决定：「贴吧遗老」）+ 一句锐评 + 品牌条
- 成分条是卡片的视觉锤：多人晒卡时构成天然对比

## 6. 埋点与测试

- 埋点：沿用 02 全套（含 `q_answered` 完测率）
- 测试：引擎 v2 tags 模式单测（聚合、占比归一、平手主成分决策、linear 回归不破坏 02）；题库 lint（tag 拼写、题数、锚点年龄完整）

## 7. 风险

| 风险 | 应对 |
|------|------|
| 梗的时效判断翻车 | §4 双人审 + 年代标注制度；被嘲的梗 24 小时内热修（配置改字段即可） |
| 与 02 班味检测受众重叠、发布撞车 | 间隔 ≥2 周发布；本站受众更泛（不限打工人），投放渠道侧重怀旧向社群 |
| 引擎升级引入回归 | linear 模式全量单测保底；02 站点构建产物 diff 检查 |

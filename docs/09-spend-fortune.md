# 09 · 花光首富的钱（A 级）

> 2026-08-04 · 状态：设计完成，排队 · 形态：纯前端，商品库驱动

## 1. 一句话

给你 ¥3,000 亿，商品从 ¥5 的煎饼果子到 ¥120 亿的 A380，看你几分钟能花完，最后生成一张购物清单卡：「我花光了首富的钱，买了 47 架私人飞机和 2 万个煎饼果子」。

## 2. 传播机制

- **情绪钩子**：荒诞快感（「原来 3000 亿这么难花」是每个玩家的第一反应，也是最强的口播传播语）+ 财富数量级的具象化教育意义
- **转发动机**：购物清单人人不同（个性化）+ 成就彩蛋（猎奇玩法值得炫耀）
- **对标**：Spend Bill Gates' Money 十年长盛（neal.fun 同款机制），中文精致版是空档

## 3. 玩法设计

- 顶部：余额大数字（实时递减，数字滚动动效是爽感来源）
- 商品网格：图标 + 名称 + 单价 + [买入/卖出] + 持有数量；点击买入余额立减
- 结算：余额 < 全场最低价时触发「你花光了首富的钱」→ 结算页（用时 + 购物清单 + 最贵单品 + 称号）→ 清单卡
- **成就彩蛋**（结算称号，驱动重玩与炫耀）：
  - 全买同一件（如 6000 万个煎饼果子）→「偏执狂企业家」
  - 5 分钟内花完 →「散财童子」
  - 只买 ≥1 亿的商品 →「批发富豪」
  - 反复买卖 100 次 →「量化之神」
- 「首富」全程虚拟化，不出现任何真实人名与企业名

## 4. 商品库（核心资产与主要工作量）

- 100+ 项 JSON：`{ 名称, 单价, 图标, 价格来源备注, 分类 }`
- 价格跨度设计（荒诞感来自真实，每个数量级都要有代表作）：
  - ¥5~100：煎饼果子、奶茶、电影票
  - ¥1k~10k：iPhone、一年房租（三线）
  - ¥10w~1000w：帕拉梅拉、北京学区房、一块奥运金牌的奖金
  - ¥1亿~100亿：私人飞机、A380、一支中超球队、发射一枚火箭
  - ¥100亿+：摩天大楼、一条地铁线、一颗人造卫星星座
- **价格来源备注是必填字段**：公开可查的口径（新闻/官方定价），评论区扒错价是本站最大口碑风险，考证要花心思
- 金额全程 Number 安全范围内（3×10¹¹ << 2⁵³），仍统一用「分」为单位整数运算，杜绝浮点误差

## 5. 分享卡片

- 购物清单卡（3:4，走 `shared/share-card`）：称号 + 用时 + Top5 购买项（名称 × 数量）+ 「共花掉 ¥3,000 亿」+ 品牌条
- 清单排序按花费金额降序，最贵的猎奇单品在顶部

## 6. 埋点

标准三事件（`generate` = 触发结算）+ `achievement`（带称号 id，看哪种玩法流行）。辅助看**平均游玩时长**（衡量玩法上瘾度，预期 > 3 分钟）。

## 7. 测试

- 结算与成就判定纯函数单测（含边界：正好花完、买卖对冲、成就叠加时的优先级）
- 商品库 lint（构建期）：字段完整、价格为正整数分、来源备注非空
- 数字滚动动效在低端安卓机不掉帧（手工验收）

## 8. 风险

| 风险 | 应对 |
|------|------|
| 商品价格被扒错 | 来源备注制度 + 上线前全库过一遍；被指错就改并在页脚放「价格勘误」入口变劣势为互动 |
| 与英文原版雷同的抄袭观感 | 机制致敬、内容全原创（中文语境商品库 + 成就系统是原版没有的）；页脚注明灵感来源，姿态大方 |
| 玩一次就走（复玩率低） | 成就系统给重玩理由；接受一次性属性，本站定位就是传播件不是留存件 |

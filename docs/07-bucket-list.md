# 07 · 余生清单（S 级）

> 2026-08-04 · 状态：设计完成，候选排期 · 形态：纯前端，零运行成本
> 与 [01 人生进度条](01-life-grid.md) 情绪同源，发布策略上错峰（见 §9）

## 1. 一句话

勾选你热爱的事，算出「你这辈子还能：吃 812 次火锅、看 45 次樱花、和最好的朋友见 138 面」，生成一张余生清单卡。

## 2. 传播机制（为什么是 S 级）

把 01 里最扎心的「剩余次数」机制放大成主角，并加上两个 01 没有的东西：

- **参与感**：清单是用户自己勾的，人人不同——个性化内容天然抗审美疲劳，卡片内容即人设表达（「我的清单里有演唱会和看海」）
- **情绪校准**：01 的底色是恐惧（人生所剩无几），本站的底色是**珍惜**（每一次都算数）——更适合发朋友圈，配文空间大（「和喜欢的人多见面」）
- **转发动机**：晒清单（自我表达）+ @人（「我们还能见 138 面，约起来」——清单里的社交项自带 @ 对象）

## 3. 用户流程

```
输入屏：出生年份 →（可选：预期寿命滑块，默认 78）
清单屏：默认池勾选（每项可调频率）→ 支持自定义项 → 「生成我的余生清单」
结果屏：清单列表（按剩余次数升序，最稀缺置顶）→ 保存清单卡
```

全程本地计算，明示不上传。

## 4. 默认清单池（v1 · 20 项，配置化 JSON）

每项：名称 + icon + 默认频率 + 频率单位（次/年、次/月）。示例：

| 项 | 默认频率 | 备注 |
|----|----------|------|
| 吃火锅 | 2 次/月 | 高频代表，数字大而具体 |
| 看电影（影院） | 1 次/月 | |
| 见最好的朋友 | 6 次/年 | 社交扎心主力 |
| 回家吃爸妈做的饭 | 4 次/年 | 与 01 的父母文案呼应，频率独立 |
| 看樱花 | 1 次/年 | 低频稀缺代表 |
| 看海 | 2 次/年 | |
| 看演唱会 | 2 次/年 | |
| 看雪 | 3 次/年 | 按城市差异大，鼓励自调 |
| 过生日 | 1 次/年 | |
| 看世界杯 | 0.25 次/年 | 四年一次的写法，出「还能看 13 届」 |

其余 10 项实现期补齐（旅行、露营、烟花、春晚、体检…），标准：**具体、可数、有画面感**；抽象项（「开心」「恋爱」）不进池。

- 自定义项：名称（≤8 字）+ 频率，上限 5 个——自定义项是彩蛋来源（「还能撸猫 4,160 次」），也是清单池迭代的用户输入（见 §7 埋点）

## 5. 计算规则（纯函数，`lib/list-math.ts`）

- `剩余年 = max(0, 预期寿命 − 当前年龄)`（复用/对齐 01 的 life-math 口径）
- `剩余次数 = floor(剩余年 × 年频率)`；月频率先归一化为年频率
- 边界与彩蛋：
  - 剩余次数 = 0 且频率 > 0：显示「**下一次，可能就是最后一次**」（不显示 0）
  - 四年一次类（频率 < 1 次/年）：文案用「还能看 {n} 届」而非「{n} 次」
  - 年龄 ≥ 预期寿命：全清单进入奖励模式（「从今天起，每一次都是加场」），与 01 彩蛋口径一致
- 所有函数显式传入 `today`，可测

## 6. 清单卡（核心传播物）

- 3:4 竖版，走 `shared/share-card`；形态是**列表卡**：标题「我的余生清单」+ 6~8 行「事项 × 剩余次数」（超出 8 项取最稀缺的 8 项）+ 一句收尾文案 + 品牌条
- 收尾文案固定正向：「数字不是倒计时，是提醒你每一次都算数」
- 行排序 = 次数升序，最稀缺在最上面（第一眼最扎心）

## 7. 埋点

标准三事件 + `item_selected`（带清单项 id，含自定义项名称的脱敏统计——只记「使用了自定义」不记内容）。勾选分布数据用于迭代默认池排序与增补。

## 8. 测试

- list-math 单测：频率归一化、0 次边界、届数写法切换、奖励模式、闰年无关性
- 清单卡渲染 smoke：8 项截断、长自定义名截断
- 四环境保存路径手工验收（工厂标准清单）

## 9. 与 01 的关系（发布策略）

- 情绪同源，**间隔至少 3 周发布**，避免受众疲劳与自我竞争
- 优先级判断：若 01 保存率 > 5%（爆款），本站作为「续作」顺势推出吃余温；若 01 表现平平，本站文案往「轻快珍惜」进一步偏移后再上，作为同机制的第二次测试——两站互为 A/B
- 代码上共享 `shared` 与年龄计算口径，但站点独立，不互相引流干扰数据

## 10. 风险

| 风险 | 应对 |
|------|------|
| 被归为「贩卖焦虑」 | 底色是珍惜不是恐惧；正向收尾固定；频率全部用户可调（数字是自己算的） |
| 清单池不够共鸣（南北/代际差异） | 池子配置化，上线后按 item_selected 数据两周一轮换血 |
| 与 01 左右互搏 | §9 错峰策略；两站卡片视觉明确区分（01 作业本格线·红笔批改 / 本站暖色手账·贴纸胶带） |

# 19 · MBTI 受难日历（B 级 · 简版设计）

> 2026-08-04 · 状态：待触发 · 触发条件：08 赛博求签验证成功（7 日复访 > 15%）且文案产能有富余时，作为求签引擎换皮
> 形态：纯前端，复用 08 的 hash 日更引擎

## 1. 一句话

选你的 MBTI，每天一条本型格专属受难事项——「INFP 今日受难：想到一件尴尬往事，原地去世 3 分钟」——受难卡可晒可@同类。

## 2. 传播机制

MBTI 是现存最大的「人格标签社交货币」，@同类（「INFP 集合」）是内置传播动作；日更结构复用 08 的复访机制。B 级原因：MBTI 热度已过峰值仍在长尾；本质是**内容号逻辑**（16 型 × 每日 = 高强度文案产能需求），产品外壳薄。

## 3. 玩法要点

- 选型格（记住选择）→ 今日受难卡（受难事项 + 受难指数 + 一句安慰）
- 文案引擎复用 08：`hash(型格 + 日期)` 从该型格受难池抽取，同型格同天全网同款（**故意的**——同类今天共享同一份受难，评论区对暗号「你也是？」，与 08 的「人人不同」相反，是社群共鸣设计）
- 受难池：16 型 × 20 条起步 = 320 条（产能大头）；写法标准：具体到有画面（「原地去世 3 分钟」），拒绝星座运势式空话
- 16 型专属配色/图腾，卡片一眼认出同类

## 4. 技术与埋点

- 引擎层与 08 共享（hash 日更 + 文案池 + streak），抽到 `shared` 的前提是 08 先跑通——顺序即依赖
- 标准三事件 + 型格分布（哪型用户最活跃，反哺文案排产：活跃型格多写）

# 00a · 视觉风格分配表

> 2026-08-04 · 工厂横切文档：站点视觉风格的盘点、分配与落地规则。与各站设计文档冲突时，以本表 + 设计文档最新修订为准。

## 1. 原则

1. **风格贴情绪**：每个站的风格必须从点子自身的情绪与语境里长出来（判官→判牍、求签→黄历、网感测试→非主流怀旧），不为「不一样」而随机发牌。
2. **一站一签名**：每站只保留一个最强记忆点（签名元素），其余部分克制。签名元素同时要出现在分享卡片上——卡片是风格的传播载体。
3. **避开 AI 模板脸**：以下三种是当前 AI 生成设计的高频默认样，除非签名元素足以扭转，否则不用——
   - 米色底 + 高对比衬线标题 + 陶土色强调
   - 近黑底 + 单一荧光绿/朱红强调色
   - 细线框 + 多栏 + 零圆角的报纸样式
4. **好看的底线不谈判**（所有风格通用硬约束）：
   - 移动端优先，最小可读字号 14px，正文对比度 ≥ 4.5:1
   - 分享卡片在九宫格缩略图下仍可辨识
   - 首屏 gzip < 100KB：风格靠 CSS 与排版实现，不靠图片堆料；webfont 须子集化后评估体积
   - 尊重 `prefers-reduced-motion`；动效只出现在签名时刻

## 2. 风格盘点（工厂弹药库）

### 几何 / 结构系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 极简瑞士风 | 网格系统、字体驱动、大留白 | 全靠间距与字阶的精确，做糙即露馅 |
| 大字报 Big Type | 一个超大字/数字占满屏 | 数字要用有性格的字重；信息层级只留两级 |
| 便当盒 Bento | 圆角卡片拼盘、块块分明 | 卡片尺寸要有节奏（1×1 / 2×1 混排），全等分就平庸 |
| 编辑部杂志风 | 衬线标题、栏式排版、印刷质感 | 中文衬线字体积大，须子集化 |

### 「糙」得好看系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 新粗野主义 Neubrutalism | 粗黑描边、高饱和撞色、硬阴影偏移 | 阴影统一一个偏移方向；色数 ≤3 |
| 孟菲斯 Memphis | 80s 几何波点斜线撞色 | 图形做装饰层不抢内容 |
| 极繁主义 | 贴纸密铺、信息轰炸 | 需要海量素材，成本高，慎选 |

### 质感拟物系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 拟物复古 | 真实物件：小票、计算器、车票、信纸、作业本 | 物件要与内容功能同构（小票=账单）才成立 |
| 玻璃拟态 | 磨砂透明层叠 | 深色底上才通透；对比度易翻车 |
| 黏土拟态 | 3D 软陶圆润 | 依赖插画资源，无现成素材慎选 |

### 怀旧电子系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| Y2K 千禧 | 金属铬、彩虹渐变、贴纸、闪光 | 中文语境可直通「QQ 空间非主流」记忆 |
| 蒸汽波 | 霓虹紫粉、网格地平线 | 已略过气，作为 Y2K 的备选色向 |
| 像素 8-bit | 红白机、马赛克字 | 中文像素字体稀缺，数字/图标像素化+正文常规字的混搭更现实 |
| 终端黑客风 | 绿字黑底等宽字 | 等宽中文排版难看，只适合数字重的站 |

### 情绪手作系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 手绘涂鸦 | 手写笔迹、纸胶带、拍立得 | 手写字体授权与体积是主要成本 |
| 手账风 | 清单、贴纸、暖纸色 | 与手绘涂鸦区分：手账更整洁、格线感 |
| 可爱软萌 | 马卡龙色、大圆角 | 受众偏窄，慎作主风格 |

### 中式系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 国潮新中式 | 传统纹样 + 现代排版、朱红金 | 纹样用 SVG 线稿控体积 |
| 仿古文书 | 判牍/黄历/奏折的纸墨印章美学 | 竖排用 `writing-mode`，注意移动端行宽 |
| 新春年画 | 剪纸、窗花、红金 | 强节令，只配节令件 |

### 氛围光影系

| 风格 | 特征 | 落地要点 |
|------|------|----------|
| 渐变弥散极光 | 深底弥散光斑发光 | CSS 渐变 + blur 实现，杜绝大图 |
| 游戏 HUD | 科幻面板、角标、扫描线 | 边框装饰用 clip-path，克制用 |

淘汰不用：新拟态（对比度差、已退潮）。

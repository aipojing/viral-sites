# 17 · 亲戚称呼计算器 · 精致版（B 级 · 简版设计）

> 2026-08-04 · 状态：待触发 · 触发条件：节令件，每年 1 月中旬启动、春节前一周上线
> 形态：纯前端，关系推导算法驱动

## 1. 一句话

点选关系链（爸爸的 → 表哥的 → 女儿），告诉你该叫什么——外加方言版（粤语/北方话）和反向查询（「三舅姥爷是我的什么人」），春节饭桌保命工具。

## 2. 传播机制

春节刚需 + 年年爆一轮（已有名站 passer-by.com 每年春节仍被翻出来转，说明**需求 > 供给质量**）；转发场景是「转到家族群」——中文互联网最难进又最值得进的传播场域。B 级原因：强节令（一年只有两周窗口）+ 已有成熟竞品，值得做但不值得急。

## 3. 差异化（对 passer-by.com）

- **称呼卡**：查完生成「这是我三舅姥爷」关系图卡（关系链可视化 + 称呼大字），竞品只有文字结果没有可晒产物
- **方言称呼**：北方官话 / 粤语两套起步（「外婆/姥姥」之争本身就是传播话题，页面可以做投票彩蛋）
- **反向查询**：输入称呼反推关系链（竞品弱项）
- 工厂级质感 + 移动端体验（竞品是 PC 时代的 UI）

## 4. 玩法要点

- 关系推导：关系链 → 称呼的映射表 + 推导规则（堂/表、姻亲、辈分升降），是个规则引擎小算法，纯函数可测；开源社区有成熟映射数据（relationship.js 等）可作数据参考底座，规则实现自研
- 输入交互：点选式关系链构建（「我 → 的爸爸 → 的表哥」逐级点），支持撤销一级
- 彩蛋：超长关系链（≥6 级）出「建议直接叫『您好』」

## 5. 埋点与启动前问题

- 标准三事件 + `dialect_used`（方言查询渗透）+ `reverse_used`；节令件观察期 3 天（工厂 SOP 的热点档）
- 启动前回答：粤语称呼数据的靠谱来源（找母语者审校，错了在广东人面前是重大事故）；与竞品正面撞车的舆论姿态（页脚致意前辈站点，姿态大方）

# 17 · 亲戚称呼计算器 · 精致版（B 级）

> 2026-08-04 · 状态：设计完成，待节令触发 · 形态：纯前端，称谓规则与地域词库驱动
> 触发窗口：春节前 35 天启动、前 10 天上线；不再写死公历 1 月中旬

## 1. 一句话

点出关系链，马上知道饭桌上该怎么称呼；结果同时解释辈分、父系/母系和常见地域叫法，不把一个答案冒充全国标准。

## 2. 用户价值与 B 级判断

春节是中文亲属称谓需求最集中的场景：用户站在门口、饭桌旁或家族群里，需要十秒内得到一个能开口的答案。成熟竞品已经验证了长期需求，本站不靠「也能算」竞争，而靠：

- 移动端单手点选，紧急查询不需要理解复杂语法
- 结果解释「为什么这么叫」，而不是只吐一个词
- 常见地域别称与不确定性提示，减少家庭差异导致的翻车
- 一张能发进家族群的关系图卡

B 级原因：流量高度集中在春节前后，且基础规则已有强竞品；它值得作为节令快反件，不值得全年抢占排期。

## 3. 核心场景与范围

v1 支持三个入口：

1. **关系链查询**：我 → 妈妈 → 哥哥 → 女儿，该叫什么
2. **称呼反查（Beta）**：输入「三舅姥爷」，查看可能的关系链
3. **热门速查**：春节高频的舅舅、姨父、妯娌、连襟等快捷入口

首版覆盖三代以内的血亲、常见姻亲和堂/表关系。极远房、重组家庭、收养关系和少数民族特有称谓不强行给唯一答案；无可靠词库时明确说「不同家庭叫法差异较大」。

## 4. 用户流程

### 4.1 关系链查询

1. 首屏直接问「TA 是你的谁的谁？」并显示一排关系按钮
2. 每选一级，顶部形成可撤销的面包屑：「我 → 妈妈 → 哥哥」
3. 只有规则需要时才追问对方比中间人年长/年幼，或询问用户性别语境；不在首屏一次收集全部条件
4. 实时显示候选称呼，关系足够明确后进入结果
5. 结果页展示标准称呼、常见别称、关系解释和称呼卡

### 4.2 反向查询

用户输入一个称呼后，返回一到多个可能关系，按常见程度排序。结果必须写「可能是」，不能把有歧义的口语称谓伪装成唯一关系。用户可补选地区或家庭习惯缩小范围。

## 5. 结果信息设计

结果页的第一层只回答「建议叫：舅舅」；第二层再解释：

- 完整关系链
- 辈分和父系/母系
- 为什么是「堂」或「表」
- 常见别称，例如「外婆 / 姥姥」
- 置信状态：明确 / 有地域差异 / 关系信息不足

如果存在多个都正确的叫法，按「普通话常用」「地区常用」「家庭自定义」分组，不用红叉判错。超长链条 ≥6 级时可以显示彩蛋「稳妥方案：先叫您好」，但必须同时保留真实计算结果，不能拿彩蛋代替答案。

## 6. 地域词库与内容审核

v1 默认词库是普通话常见称谓；地域包是独立、可关闭的数据层：

- 首个地域包只在找到可靠资料和至少两位母语者逐条审核后上线
- 「北方话」范围过大，不作为一个笼统方言包；可先做清晰地区标签，如京津冀常见叫法
- 粤语包同时给汉字、粤拼/读音提示和使用地区，不用普通话谐音代替
- 页面允许用户提交「我家这样叫」，但用户提交只进入待审核池，不实时成为标准答案

所有词条保留来源、审核人角色、适用地区和最后复核时间。方言数据不够完整时宁可显示「暂未覆盖」，不能靠模型猜。

## 7. 分享卡与视觉

称呼卡是本站相对竞品的传播增量：

- 中心大字显示称呼
- 族谱式关系链从「我」连接到目标亲属
- 地域别称只显示一个用户选中的版本
- 一句场景文案：「春节饭桌称呼已通关」
- 品牌条与回站提示

视觉使用新春年画国潮：剪纸红、洒金和墨色，签名元素是族谱式关系图。纹样只做边角，不牺牲关系链可读性；春节后仍能使用，因此不写具体生肖，避免每年重做主视觉。

## 8. 搜索与传播

- 常见查询组合具备稳定搜索意图，重要关系应有可索引的解释页，而不是只有客户端交互结果
- 节前传播重点是家族群和同事群的实用转发，默认分享语是「过年别叫错，这个能查」
- 「南北方到底怎么叫」可以做已审核数据上的结果对比，不做无来源投票后直接宣布标准答案
- 页脚大方注明同类产品与公开资料的启发，差异化落在移动体验、解释层和分享卡

## 9. 埋点与成功标准

- `query_started` / `query_resolved` / `query_unresolved`
- `relation_step_added`：只记关系枚举，不记用户姓名
- `reverse_used`、`region_pack_used`
- `generate`：得到可用称呼结果
- `save_image`：保存称呼卡
- `source_opened` / `correction_submitted`：衡量用户对准确性的需求

按节令件 3 天窗口判断：查询成功率 ≥90%，从进入到结果的中位时长 <20 秒，结果卡保存率 ≥10%，家族群式分享带来的回流 ≥8%。`query_unresolved` 前 20 项直接决定下一轮词库补齐，不用总访问量掩盖准确率问题。

## 10. 风险、测试与上线 gate

| 风险 | 应对 |
|------|------|
| 地域和家庭叫法不同，被认为算错 | 多答案与置信状态；地域包；明显的纠错入口 |
| 规则引擎边界复杂 | 高频关系回归集 + 人工家谱样例盲测；结果解释与称呼一起测 |
| 正面撞上成熟竞品 | 不宣称首创；聚焦移动端、解释和可分享关系图 |
| 春节窗口错过 | T-35 冻结范围，T-21 完成词库审核，T-10 上线；错过 T-10 当年不赶工 |

上线前硬 gate：普通话高频关系至少 200 条人工回归样例全过；任何地域包有两位对应地区母语者审核；隐私说明确认不上传关系链。若无法在春节前 10 天达到准确性标准，则顺延一年，不做节令半成品。
